# 열화상 점검 작업대 (ThermoLog)

기존 **분전반 / 전열기기 열화상 측정 엑셀 양식**을 바꾸지 않고 입력하는 모바일 대응 웹사이트입니다.

이 프로젝트에는 사용자가 제공한 `분전반리스트(세종나성).xlsx`가 초기 등록 현장으로 포함되어 있습니다. 실행하면 **세종나성점 50개 항목**이 자동으로 표시되며, 다른 현장의 **같은 구조** 엑셀도 추가할 수 있습니다.

## 기능

- 여러 현장을 각각 등록하고, 현장별 점검 기록을 독립적으로 보관
- 엑셀에서 **층수 / 판넬(장비) 명칭 / 설치위치 / 항목 번호**를 자동 인식
- 층별 필터, 검색, 측정 완료/미측정 필터, 진행률 표시
- 판넬 클릭 → **카메라 촬영(또는 앨범 사진)** → **엑셀의 실제 사진 영역 비율에 맞춰 드래그·확대하며 자르기** → 최고온도와 점검일 입력
- 저장된 결과 수정·삭제 및 현장명 변경
- **언제든지 엑셀 다운로드**: 원본 엑셀의 시트·서식·셀 병합·인쇄 설정·기타 열을 유지하고 **점검일/최고온도/지정 사진 칸만** 추가 또는 갱신
- 로컬 SQLite와 사진 파일로 데이터를 서버에 지속 저장 (브라우저를 껐다 켜도 유지)
- Docker 실행 시 비밀번호 로그인 지원

## Docker 실행 (권장)

Docker 및 `docker compose`가 설치된 컴퓨터/서버에서:

```bash
cp .env.example .env
```

`.env` 파일의 `APP_PASSWORD`를 **꼭 본인이 사용할 강력한 비밀번호로 변경**한 다음:

```bash
docker compose up -d --build
```

- PC: `http://localhost:8000`
- 동일한 네트워크의 휴대폰: `http://서버-IP:8000`
- 인터넷에서 휴대폰으로 접속할 때는 **HTTPS가 설정된 역방향 프록시 / Cloudflare Tunnel** 사용 권장
- 사진·현장 정보는 Docker의 `panel_data` 이름 붙은 볼륨에 저장됩니다. 해당 볼륨을 주기적으로 백업하세요.

> 주의: 외부 네트워크에 공개하는 경우 로그인 비밀번호와 HTTPS를 필수로 설정하세요. 로그인만으로 일반적인 인터넷 서비스 수준의 보안 운영이 완성되는 것은 아니므로, 가능하면 Cloudflare Access 또는 VPN 등의 접근 제한을 추가하는 것을 권장합니다.

## Windows에서 직접 실행

1. Python 3.11 이상 설치
2. `run_windows.bat` 더블클릭
3. 브라우저에서 `http://127.0.0.1:8000` 접속

Windows 실행 스크립트는 **기본적으로 해당 PC에서만** 접속 가능하도록 되어 있습니다. 휴대폰에서도 연결하려면 비밀번호를 지정한 뒤 터미널에서 다음을 실행하세요.

```powershell
$env:APP_PASSWORD = '충분히-긴-비밀번호'
.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000
```

방화벽에서 8000 포트의 LAN 접근을 허용해야 할 수도 있습니다.

## Linux에서 직접 실행

```bash
./run_linux.sh
```

또는 개발 실행:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
APP_PASSWORD='충분히-긴-비밀번호' uvicorn main:app --host 0.0.0.0 --port 8000
```

## 사용하는 방법

1. 처음 실행하면 세종나성점 목록이 보입니다. 다른 현장은 **현장 엑셀 등록**으로 `.xlsx` 파일을 올리세요.
2. 현장 선택 → **층수 필터** → 판넬/장비 선택
3. 촬영 또는 앨범 사진 선택 → 사진을 드래그/확대해 **엑셀 셀 사진 영역에 맞춰 자르기**
4. **최고온도(℃)**와 **점검일** 입력 → 측정 결과 저장
5. 언제든지 **엑셀 다운로드**를 누르면 현재까지 측정한 정보가 들어간 파일을 내려받습니다.

판넬을 다시 눌러 촬영 사진을 바꾸거나, 기존 사진을 유지한 채 온도만 수정할 수도 있습니다.

## 호환되는 엑셀 양식

현재 지원되는 `.xlsx`는 다음 조건을 만족해야 합니다.

- 점검 관리대장 시트의 헤더에 `층수`, `판넬명칭` 또는 `장비명칭`, `설치위치`, `점검일`, `최고 온도`가 있음
- 측정 항목에 고유한 구분 번호가 있음
- 열화상 사진 시트에 항목 구분 번호와 각 번호의 **병합된 사진 영역**이 있으며, 초기 샘플과 유사하게 배치됨
- 기타 시트 제목, 현장명, 층수, 판넬명칭 및 항목 수는 달라도 됨

**아예 다른 레이아웃**(사진 시트의 위치 규칙이나 헤더 구성까지 다른 파일)은 자동 처리하지 못할 수 있습니다. 이 경우 업로드 시 오류 메시지를 보여줍니다.

## 엑셀 원본 보존 원리

Excel의 Office Open XML(`.xlsx` ZIP 패키지)을 직접 패치합니다. 새 통합문서를 처음부터 재생성하지 않고, 원본 엑셀의 **해당 점검일/온도 셀 값만 교체**하며, 열화상 사진 시트에는 지정 위치에 **그림 앵커(DrawingML)**만 추가합니다. 다른 기존 파일 부분과 셀 서식, 병합 범위, 기존 시트 구조 및 인쇄 설정은 유지합니다. **저장되는 사진은 엑셀 사진 칸 비율로 크롭 후 JPEG로 저장**합니다.

현재 샘플의 사진 영역 비율은 약 **1.59 : 1**이며, 다른 현장의 파일에서는 사진 영역 크기를 읽어 자동 계산합니다.
